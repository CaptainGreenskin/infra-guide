# 中文教材质量目标

目标读者：需要建立全貌的初学者，以及准备 Cloud、AI Infra、Agent Infra 岗位面试的工程师。
参考 AIInfraGuide 的讲解组织，独立撰写正文、程序和图。章节数量与字数不代表教学质量。

每章按以下问题验收：

1. 开头能说明本章问题、必要先修和学完能判断什么吗？
2. 新术语是否就近用中文解释，变量、单位和观察时点是否明确？
3. 是否沿同一组输入讲清“条件—机制—结果”，而不是连续堆结论？
4. 算例能独立跟算吗？换题设时是否明确标出？
5. 图是否解释结构、时序、数量或边界，读完能推出一个结论？
6. 代码是否解释前文机制，完整源码与验证记录是否一致？手册、模型与实测是否分清？
7. 是否有一个能推翻常见误判的反例，以及回到知识点的复习出口？

本轮范围：63篇主线，逐章保留审查意见；43篇保留，16篇局部修正，4篇重组。
先完成高优先级事实与机制缺口，再复核阅读连贯性；最后完成实验、链接和桌面/手机检查并发布。
保留篇不表示永远无需改动，后续读者反馈仍可重新打开问题。

验收是编辑内审，不等于真实读者已快速掌握，也不承诺任何公司的面试覆盖率。
后续由公开仓库问题反馈收集具体阅读断点：章节、原句、哪里没看懂、预期解释。
不以“加了多少字、多少图”作为完成标准。
