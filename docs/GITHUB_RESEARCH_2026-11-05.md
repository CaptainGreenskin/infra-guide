## 对原15仓研究的取舍

原15仓提供了四组不同帮助，不能混成“每个仓库都采用同一种教学模板”：

- JavaGuide、小林、CS-Notes、huihut、后端讨论题：知识范围、中文解释、条件变化与复习追问。速查条目需要补成本站的连续章节。
- System Design Primer、DevOps Exercises、Kubernetes Handbook：全局地图、需求与约束、操作目标及故障证据。练习和解答保留明确入口。
- AIInfraGuide、AI-Infra-101、ai-infra-book、训练面试整理：计算、状态、形状、数据路径与资源预算。先补模型和数值概念，再展开底层优化。
- 微软Agent入门、MCP SDK、τ²-bench：工具调用分工、协议边界、任务与独立验收。实现参考不能写成已接入Kairo或已完成目标环境验证。

因此，结论是：这些样本支持“全貌与深读分层、先建立对象关系、用例子推进机制”的方向；它们并不共同保证每个陌生词都已解释。本站面向中文初学者，必须在此基础上明确写出每一章的概念依赖。
