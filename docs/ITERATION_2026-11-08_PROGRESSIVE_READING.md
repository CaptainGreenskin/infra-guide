# 逐层讲解与连续阅读

这轮继续处理整体课程的可读性。统一全站小节名称，同时实际重写六章的解释顺序；标题修改没有替代正文修改，也不以字数或自动检查数量判断读者已经掌握。

## 全站阅读结构

每章保留原URL、编号、完整标题、section编号和既有子锚点。显示小节名按真实内容命名，用概念、关系、机制或实战对象告诉读者本节讨论什么。正文、桌面目录、手机目录和搜索使用同一份显示标题。

三个原有入门章与这轮六章已在正文内交代基本对象和依赖，因此将原三步概念预览放到章末，折叠为回顾。正文首次术语解释从空集合开始，不假定读者看过回顾。其余章节的前置概念介绍仍保留，后续逐章检查后再决定位置。

详细程序和验证材料可以展开阅读。旧的深链接依然打开原目标及其折叠祖先；手机本文目录选择一组折叠实战时，也会打开实际内容。章节名称、知识点关系图、学习路线、岗位上下篇和实验证据维持原连接。

六章保留原有完整代码、图和执行记录。不同算例明确说明变化了哪些输入；权限与恢复章节说明独立测试夹具的标识和结果值，避免把同角色的不同实验当作同一次执行。数值结论继续由既有独立算例、源程序和执行记录核对。
