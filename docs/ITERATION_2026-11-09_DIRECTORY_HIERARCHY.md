# 目录层次与概念名称

## 问题

参考文章的优点是课程目录、单篇文章和页内小节各有职责。本站侧栏已有简短概念名和主题分组，全站大纲却使用长标题平铺同一组文章，读者换入口时会丢失原来的层次。

## 本轮范围

- 全站大纲和章节侧栏共用目录分组与概念名称；文章页保留完整标题。
- AI 基础按模型计算、GPU 与算子分组；平台按训练作业、推理服务和生成优化分组。Agent 沿任务与工具、状态与恢复、工作流与检索、Kairo 接入展开。
- 训练目录的分组直接命名知识范围，替代“建立”“理解”“完成”等学习活动。没有子主题的领域不增加空分组。
- 大纲的领域继续使用原生展开控件；章链接直接进入正文。完整文章标题保留在链接的 title 属性中。移除与首章行重复的“从本领域第一章开始”链接；章链接字号提高至 15px、组名为 14px。

本轮只调整目录展示，不变更章的编号、先修顺序、正文、发布日期、实验结果与公开 URL；V65 已发布审阅记录保持原样。三主线、78 章、14 个领域图谱、7 条岗位路线不变。

## 验收

运行现有 `node scripts/check-all.cjs --pages`，核对全站生成页面、旧锚点与根路径/Pages 路径。另对大纲与侧栏做一次性顺序、分组、完整标题与直接阅读链接核对，并检查桌面和手机展开目录、进入文章及返回大纲。

目录更一致不代表真人已掌握知识。试读样本仍为 0；正文中重复教学包装及尚未逐章复核的解释继续属于后续工作。
