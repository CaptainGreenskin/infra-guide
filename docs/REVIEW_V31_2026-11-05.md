# 第31轮：实验按学习顺序组织，读者能找到近期补强

公开页实际检查发现：实验室仍只有16张混合方向的卡片，近期第22至29轮的新实验缺少统一入口。卡片标题强调包的组合，没有给初学者一条运行顺序。本轮整理现有实验，不把目录任务数计作新增实验或实质章节数。

## 三个方向，各有顺序

新目录为47项学习任务：Cloud18、AI15、Agent14，关联全部21个现有ZIP。Cloud的系统前置单独作为选读，其余17项按资源/请求→数据/事件→交付/恢复推进。AI从标准库Attention开始，再进数据加载、真实CPU两rank、状态、产物和完整恢复。Agent从权限与工具效果开始，再进接管、取消、上下文、检索、观测和独立评估。

每项明确要观察的变化、环境、验证范围，提供先读机制、章节运行段、下载和记录。源码文件名可展开；相同包的不同任务只列自己的程序，不假设读者会运行整包。整包可能包含跨方向的独立实验，目录已直接说明。

方向链接使用可分享的`?track=cloud/ai/agent`；无效值回到全部。默认静态HTML包含47项和原生展开控件，不依靠JavaScript生成目录；筛选由运行时增强。顶部4个选择入口在手机排成2列，点击区域44px。任务正文15px（手机14px）、标题17px以上，环境与范围弱化展示，运行链接使用明确蓝色。移动端链接区域至少32px，避免挤成一排小字。

首次出现的rank/worker解释为训练进程和数据加载进程；span解释为跨度；inbox/outbox用去重记录/待发事件解释。正文仍在知识章节，目录不重复完整代码和长篇理论。

图和内容更新仍累计21篇不同章节，Cloud8/AI6/Agent6/共享1；66/66章、95/95点的审读摘要继续匹配。本轮目录不改变该计数，也不冒领新的实测程序。
