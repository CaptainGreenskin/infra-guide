# 第33轮：让中文读者更快找到合适资料

本轮改资料发现与阅读入口，不增加24篇实质章节计数，也不把课程链接当作本站讲解。66章、95知识点审读记录保持；存储章与接口知识点的小幅修订重新绑定内容摘要。

## 正文语言、录像语言和学习位置

32项原始资料支持正文语言与视频入口的组合筛选。8项中文或官方译文中，4项带视频入口；筛选保留在URL内，方向及条目跳转保留选择。未识别参数回到全部资料，静态全文仍包含全部32项。

增加《动手学深度学习》原作者中文书与2021归档课程，按自动求导、损失、Attention及多GPU基础取用；归档API不冒充当前运行环境。增加PAI-DLC中文作业文档，帮助读者对照镜像、代码/数据挂载、角色/副本、网络和日志；未执行付费云任务。

Hugging Face Agents只将已核对的第1单元切到简中入口，保留英文原文；视频按钮明确是英文课程导览。AWS可靠性切到官方中文并保留英文。MCP官方中文入口未取得可验证内容，保留官方英文，未使用非官方镜像补齐。章节相关性不变时中文优先，One GPU LM原有用户推荐仍保留。

条目显示各自核对日，历史课程显示归档年份。只核对目录和列出入口，没有声称完整观看所有视频。

## 国内产品名与通用接口

存储章和storage-model知识点加入阿里云、腾讯云、AWS的块/共享文件/对象对照。产品名核对阿里云和腾讯云原文，仅映射接口类别；不摘抄厂商性能排名，也不将多挂载推广为普通文件系统安全多写。

## 字体与实际阅读检查

移除Google Fonts外部导入，按系统中文字体顺序回退，不引入字体下载或新依赖。此改动消除外部字体依赖，没有声称测得网络提速。

实际浏览器在1280px桌面和390px手机检查资料页、两次筛选、方向/条目跳转、详情展开及产品表。手机筛选44px高，资料页整页390px；四列表格为440px，在348px局部容器内滚动，未撑宽页面。方向和条目保留悬浮导航避让距离。

新增资料检查纳入单一入口：资源集合、语言/媒体条件、相关中文排序、原文与视频语言、查询编码、产品对照实际表格和无远端字体依赖。全量27项（含Pages）通过；100路由仍输出完整初始HTML，源码/runtime输出一致，10188条项目站本地链接和资源通过。

发布状态以匹配源码的GitHub Actions与镜像版本为准。没有云端DLC、GPU、Kairo、真实用户增长或面试覆盖率的新增实测。
