# 观察者评分参考

每问0–2分：0为核心机制错误；1为方向正确但遗漏关键条件；2为概念关系、条件和判据均清楚。没读到或时间不足用`not_reached`，不写0。首次阅读与复读分开记录；原话先于评分。

## Cloud

- 连接/字节/消息：2分应说明TCP连接提供有序字节流，发送/接收分段不等于消息边界；应用协议负责恢复消息。只说“TCP可靠”未解释边界，为1分。
- ET：2分应指出没有新通知仍可能有未读数据，需解释实际读返回值；把没有事件当成已经排空，为0分。
- 迁移：保留应用级就绪责任，按预算轮转读ab、cd、ef，再尝试到EAGAIN后交回内核等待；异常/结束另走对应路径。只说“一直读完”却未处理公平预算，为1分。

## AI

- softmax：减去同一最大值保持指数比例，并限制最大指数为1；还需说明本章有限输入和轴的前提。只说“防止溢出”而无法说明为何结果不变，为1分。
- 求和：加法舍入与顺序改变相关；浮点不满足通常的结合律，树形不保证总比所有顺序更准。仅记住1/0/2而不能解释，为1分。
- 迁移：不能从不同计时边界推断实现收益。对齐输入形状、类型、布局、正确性与测量范围，预热、重复采样并记录平台；不把CPU证据推广为GPU结论。只有“再测几次”而未指出范围差异，为1分。

## Agent

- 三层：索引提出候选、权威来源提供可核对版本的正文、上下文是实际进入本次调用的材料；还要分开当前读取资格。只重复名词未说明关系，为1分。
- 预算：237包括系统约束、任务、来源ID/版本/摘要、正文和分隔文字，36只数两段正文；应按实际完整模板和分词器核对，再留输出预算。只说“模板也占地方”但把汉字等同词元，为1分。
- 迁移：不能用旧答案/引用替代当前授权、版本与必要证据。可在协议内调整预算或选择完整有效片段，仍不足则报告证据不足；发送前复检来源，真实模型答案另验。仅说“扩大top-k”没有解决最终输入缺证，为1分。

一份试读的分数用于定位修订，不按总分推断就业能力。必须保存实际用时、引用的卡点原句和对应改动；后续复读检查同一问题是否消失。
