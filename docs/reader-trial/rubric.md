# 观察者评分参考

每问0–2分：0为核心机制错误；1为方向正确但遗漏关键条件；2为概念关系、条件和判据均清楚。没读到或时间不足用`not_reached`，不写0。首次阅读与复读分开记录；原话先于评分。

## Cloud

- 连接/字节/消息：2分应说明TCP连接提供有序字节流，发送/接收分段不等于消息边界；应用协议负责恢复消息。只说“TCP可靠”未解释边界，为1分。
- 长度：2分应说明长度头描述编码后的正文字节数；TCP传输字节，字符与编码字节数可能不同，解析器需等足正文再解码。只记住某个中文例子的数字，为1分。
- 迁移：第一次只有2字节头，第二次有完整4字节头但正文只有abc，共7字节，均保留而不交付；第三次收到def，凑齐4+6=10字节后交付abcdef，消费该帧。知道第三次才齐全却未说明前两次的缓冲状态，为1分；把任意recv块直接交付为消息，为0分。

## AI

- softmax：减去同一最大值保持指数比例，并限制最大指数为1；还需说明本章有限输入和轴的前提。只说“防止溢出”而无法说明为何结果不变，为1分。
- 行和：2分应说明行和为1只是必要检查，错误位置或错误权重也可满足；仍需在同一输入、轴和约定下逐项与参考结果比较。只说“再检查一次”未给独立判据，为1分。
- 迁移：三个相等且有限的分数应产生相等权重，各为1/3；[1,0,0]虽然行和为1，逐项不符合本题softmax，不能通过。只判断错误却说不出正确比例及其原因，为1分；仅凭行和接受，为0分。浮点实现按声明误差逐项核对，不要求打印字符串恰好相同。

## Agent

- 三层：索引提出候选、权威来源提供可核对版本的正文、上下文是实际进入本次调用的材料；还要分开当前读取资格。只重复名词未说明关系，为1分。
- 版本：2分应说明文档ID定位哪份资料，版本定位哪次内容；当前任务的月份、适用条件、正文与读取资格需共同成立，旧调整99不能因排位高而代替当前27。只说“用最新的”却未说明来源与条件，为1分。
- 迁移：27只是当前调整，不能当本月总额；还需取得基础费用a-1/v1=10，与当前调整a-2/v2=27一起核对月份、单位、片段位置、版本和读取资格，完整进入上下文后才有37及两份依据。只算出37却忽略材料尚未齐备，为1分；把99或单独27直接当总额，为0分。此题不要求后续BM25、预算或真实模型生成知识。

一份试读的分数用于定位修订，不按总分推断就业能力。必须保存实际用时、引用的卡点原句和对应改动；后续复读检查同一问题是否消失。
